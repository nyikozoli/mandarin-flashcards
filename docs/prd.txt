## Goal

I want to study the 300 most useful beginner Mandarin Chinese words in a Tinder-like flashcard interface.

Every card must include:

1. Simplified Chinese characters
2. Pinyin with tone marks
3. English meaning
4. Hungarian meaning
5. One or two short, natural example sentences in Chinese
6. English translation for each sentence
7. Hungarian translation for each sentence
8. A “Read aloud” button that speaks the Chinese word and example sentence(s)

## Vocabulary requirements

- Include exactly 300 real, useful beginner Mandarin words.
- Prefer a coherent beginner / high-frequency vocabulary set roughly comparable to HSK 1-level vocabulary.
- Do not use duplicate headwords.
- Use Simplified Chinese.
- Check every pinyin spelling and tone mark.
- Keep English and Hungarian translations natural and accurate.
- Use practical example sentences at beginner level.
- Avoid machine-like or grammatically incorrect Chinese examples.
- For measure words, particles, grammar words, and similar entries, explain their function clearly in English and Hungarian instead of forcing an unnatural one-word translation.
- The content must be embedded directly in the HTML, so it works without internet access.

## Interaction design

Create a mobile-first “Tinder-style” card app.

### Card actions

- Swipe right = “I know this”
- Swipe left = “Still learning”
- Provide visible buttons as well:
  - “← Still learning”
  - “Skip”
  - “I know it →”
- Keyboard shortcuts:
  - Right Arrow = I know it
  - Left Arrow = Still learning
  - Space = skip / next card
  - S = speak the current card
- Tapping/clicking the card should hide/reveal meanings and translations.
- The Chinese word and pinyin must remain visible when the answer is hidden.

### Progress tracking

- Show:
  - Current card number, e.g. “Card 14 / 300”
  - Number marked “Known”
  - Number marked “Learning”
  - A progress bar
- Persist status in browser localStorage, so I do not lose my progress after closing/reopening the page.
- Add:
  - Shuffle button
  - Reset progress button, with confirmation
  - “Study learning cards only” mode
  - “Study unmarked cards only” mode
  - “All cards” mode
  - A searchable list view of all 300 words, including each word’s status
- In list view, allow selecting a specific card to study.

### Text-to-speech

- Use the browser’s native Web Speech API / speechSynthesis.
- Speak in Mandarin Chinese using `zh-CN`.
- Prefer an available Chinese voice if the browser provides one.
- Speak the word first, pause briefly, then speak the example sentence(s).
- If speech synthesis is not supported, show a clear, non-blocking message instead of failing silently.
